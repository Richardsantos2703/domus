# Domus

Aplicativo de gerenciamento de contas domésticas desenvolvido com Flutter e Dart.

## Sobre o projeto

O Domus tem como objetivo facilitar a organização das despesas de uma residência, permitindo acompanhar contas pendentes, atrasadas e pagas em um só lugar.

## Funcionalidades

- Cadastro de contas domésticas.
- Edição de contas existentes.
- Organização por status: pendentes, atrasadas e pagas.
- Filtros para facilitar a visualização das contas.
- Suporte ao registro de contas recorrentes.

## Tecnologias

- Flutter
- Dart
- Git e GitHub

## Status do projeto

Em desenvolvimento.

Novas funcionalidades e melhorias serão adicionadas progressivamente.

## Como executar

1. Instale o Flutter seguindo a [documentação oficial](https://docs.flutter.dev/get-started/install).
2. Clone este repositório.
3. Entre na pasta do projeto.
4. Execute:

```bash
flutter pub get
flutter run -d chrome
```
